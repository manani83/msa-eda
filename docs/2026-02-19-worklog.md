- Docker Hub 레지스트리 기반 K8s 배포 구성 및 적용.

## 상세 내용
1. 주문 생성 API 확인
   - 엔드포인트: `POST /orders`
   - 요청 바디 구조 확인 후 `curl` 예시 제공.
   - `curl` 샘플:
```bash
curl -X POST "http://localhost:8080/orders" \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "user-2",
    "items": [
      {"productId": "prod-2", "quantity": 3, "unitPrice": 2000}
    ],
    "shippingAddress": {"zip": "12345", "line1": "line1", "line2": "line2"},
    "couponCode": "WELCOME10"
  }'
```

2. SQL 로그 출력 설정
   - 파일: `app/src/main/resources/application.yml`
   - 설정 추가:
     - `spring.jpa.show-sql=true`
     - `hibernate.format_sql=true`
     - `logging.level.org.hibernate.SQL=DEBUG`
     - 바인딩 파라미터 TRACE 로깅 설정
   - 컨테이너 재기동 필요.

3. `curl` 요청 오류 해결
   - 원인: JSON에 스마트 따옴표(“ ”) 사용.
   - 해결: 일반 쌍따옴표(")로 교체한 `curl` 예시 제공.

4. K8s 배포 전환 및 적용
   - 레지스트리: Docker Hub (`manani83/hexagonal-app`).
   - K8s 매니페스트 추가: `k8s/base/*` (Deployment/Service/ConfigMap/Secret/Ingress).
   - DB 접속 URL을 외부 MySQL(192.168.135.50)로 설정.
   - 네임스페이스 `hexagonal` 생성 후 적용.
   - CrashLoopBackOff 원인을 로그로 확인하고 DB 연결 성공 확인.

5. K8s 헬스체크 개선
   - Actuator 의존성 추가 및 `/actuator/health` 노출.
   - `liveness/readiness` 제거, `startupProbe`만 사용하도록 변경.

6. 배포/운영 스크립트 추가
   - 이미지 빌드/푸시/배포 자동화: `scripts/build-push.sh`
     - 태그 형식: `dev-YYYYMMDDHHMMSS`
     - `kubectl set image`로 롤아웃
   - MySQL만 기동/종료 스크립트:
     - `scripts/mysql-up.sh`
     - `scripts/mysql-down.sh`

7. K8s 리소스 정리
   - `kubectl delete namespace hexagonal`로 전체 리소스 정리.
